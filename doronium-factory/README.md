# 도로늄 공장 — INFINITE INDUSTRY

1인칭/3인칭 탐험, 생존, 자원 채집, 지형 개조, 공장 자동화를 하나로 연결한 3D 산업 생존 게임입니다.

플레이: https://rockey-jason.github.io/doldol-site/doronium-factory/

## 월드

- 192×160 타일의 확장된 두 대륙 월드(기존 대비 2.5배 면적)와 깊은 계곡·고산 능선·화산 분지·고원 지형
- 초원, 고대 숲, 습지, 붉은 사막, 고산 지대, 빙설 산맥, 수정 협곡, 화산 지대 등 8개 생태 지형을 두 대륙에 분포
- 동부·남부 신규 구역에 자연 자원 패치를 생성하며 광물은 지표에 생성하지 않음
- 서로 다른 지역에 광산 입구 5곳 배치
- 지하 광산은 40×24 갱도이며 총 5개 심도 층으로 구성
- 표면에는 광물 광맥이 노출되지 않으며 모든 광물은 지하에서 채굴

## 시작과 스토리

첫 시작 시 ‘도로늄 행성의 마지막 불빛’ 인트로와 ORBIT의 복구 지령이 재생됩니다. 복구 프로토콜을 시작하면 신규 임무 등록 배너가 나타났다가 사라지고, 현재 목표가 게임 화면에 표시됩니다. 임무를 완료하면 보상과 스토리 대사가 나오고 다음 임무가 등록됩니다. 기존 10개 메인 캠페인과 도로늄/인피니티/행성 안정화 엔드게임 흐름을 유지했습니다.

## 광산과 Y 심도

곡괭이를 장착한 상태에서 광맥을 조준하고 사용합니다. 더 깊은 층으로 내려갈수록 희귀 광물이 등장합니다. 현재 광산의 정적 광맥 생성표에는 자연 도로늄 광맥이 없습니다. 도로늄은 공정·연구·퀘스트를 통해 생산하거나 획득해야 합니다.

| 광산 층 | 바닥 Y | 광물 예시와 광맥 Y |
|---|---:|---|
| 1층 | -42 m | 석재 -18, 구리 -26, 철 -34 m |
| 2층 | -84 m | 철 -60, 석탄 -66, 석영 -74 m |
| 3층 | -126 m | 석영 -102, 금 -108, 석탄 -116 m |
| 4층 | -168 m | 다이아몬드 -144, 금 -150, 다이아몬드 -158 m |
| 5층 | -210 m | 금 -186, 다이아몬드 -192, 석영 -198, 석탄 -204 m |

도끼는 지상의 나무와 돌이 고기 나무를 벌목하는 데 필요합니다. 곡괭이는 지하 광물을 채굴하는 데 필요하며, 도구가 맞지 않으면 채집되지 않습니다.

## 지형 준비와 공장 설치

일반 기계와 표준 컨베이어를 설치하려면 먼저 부지를 준비합니다.

1. B 키로 건설 팝업을 엽니다.
2. 땅 평탄화를 선택하고 지형을 클릭합니다. 선택한 지점 중심으로 설치 가능한 3×3 영역을 같은 높이로 정리합니다.
3. 기초 타일 설치를 선택합니다. 평탄화한 각 타일에 목재 2개와 석재 2개가 필요합니다.
4. 표준 컨베이어나 기계를 선택하고 기초 타일 위에 설치합니다.
5. 미리보기가 초록색이면 설치 가능, 주황색이면 부지 조건이 맞지 않습니다.

표준 컨베이어는 평탄화와 기초 타일이 필요합니다. 자연 적응형 컨베이어는 지형의 앞·뒤·좌·우 높이를 계산해 상판 경사와 지지대 높이를 자동 조절하므로 두 과정 없이 바로 설치할 수 있습니다. 수원지 펌프와 지정 릴레이/코어 부지는 각각의 특수 설치 규칙을 따릅니다. 광산 채굴기가 아닌 직접 채굴 방식으로 변경했기 때문에 기존 지표 광물 채굴기는 건설 목록에서 제외했습니다.

## 생존과 공장

체력·허기·갈증이 시간에 따라 감소합니다. 허기나 갈증이 바닥나면 체력이 감소하고, 둘 다 충분하면 천천히 회복합니다. 돌이 고기는 허기를, 물은 갈증을 회복합니다. 사망하면 지상으로 복귀하며 일부 원자재를 잃습니다.

기존 전력, 생산 레시피, 컨베이어 물류, 연구, 기존 게임의 15개 도로늄 변형, 7단계 인피니티 퓨전, 행성 안정화 스토리는 계속 연결됩니다. 다만 현재 변형 ID 집합은 명세 B9의 정식 Infinity 입력 15개 ID와 일치하지 않으므로, 현재의 15종 모델/레시피 검증이 정식 Infinity 재료 호환을 뜻하지는 않습니다.

연구 센터에는 별도의 엔지니어 전문화 스킬 트리가 있습니다. 탐험·채굴·제조·물류·연구 분석의 5개 분야에 20개 노드가 있고, 시작 포인트와 고유 연구/스토리/탐험 마일스톤을 통해 최대 15포인트를 획득합니다. 같은 분야의 앞 단계 노드가 있어야 다음 단계 스킬을 습득할 수 있습니다. 반복 생산이나 반복 채굴로 포인트를 얻지는 않습니다. 현재는 스캐너 거리, 채굴 반복 속도, 허용 레시피 품질 modifier, 창고/저장고 건설 자금 할인 등 일부 보너스만 게임 로직에 연결되어 있으며, 나머지 노드는 해당 하위 시스템 구현 전까지 효과 설명/해금 상태만 제공합니다.

## 저장 데이터 이전

worldVersion 3 저장 데이터는 기존 좌표와 건물·인벤토리를 유지하면서 확장 지도에 새 자연 자원만 병합합니다. 이전 버전 저장 데이터는 기존 좌표 이전 절차를 거친 뒤 새 구조로 옮깁니다. 자금, 인벤토리, 연구, 생산 기록, 임무 진행도, 기존 공장 시설을 유지하고 기존 시설을 새 월드 안으로 이동시킨 뒤 부지를 평탄화/기초 처리합니다. 시설이 새 지형 자원과 겹치지 않도록 겹친 자원은 제거합니다.

비로그인 상태에서는 브라우저 로컬 저장을 사용하고, 로그인 상태에서는 기존 dori_cloud_storage 테이블의 전용 저장 키 doronium_factory_infinite_industry_v1을 사용합니다. 새 로컬 저장은 체크섬을 검증하고 최대 3개의 이전 저장 스냅샷을 유지합니다. 주 저장 데이터가 손상되면 유효한 최신 임시 저장/백업에서 복구를 시도합니다. 이전 worldVersion과 계정별 저장 키는 유지하며, 알 수 없는 미래 schema는 덮어쓰지 않습니다. 클라우드 동기화가 실패해도 현재 기기의 로컬 저장은 유지됩니다.

## 기술 및 검증 범위

- Three.js WebGL 기반 절차적 3D 지형, 시설, 엔지니어, 갱도, 광물 렌더링
- 24×24 지형 청크 프러스텀 컬링, 장면 변경 시에만 메시 재구축, 신규 자원 공개·벨트 화물·기계 출력 개별 갱신, 반복 기하 데이터 공유
- 기기 사양에 따른 픽셀 비율·그림자·안티앨리어싱 설정과 저프레임 시 동적 렌더링 해상도 조절
- 지형/광산 레이어 분리와 GPU 인스턴싱 지형 렌더링
- 기존 도로늄 결정 도감 및 시설별 절차적 모델
- 나무·돌이 나무·수원 시각 모델은 InstancedMesh로 묶어 개별 오브젝트 렌더링 호출을 크게 줄임
- 지형 청크 32×32, 제한된 카메라 시야 거리, 모바일 그림자/광원 축소
- 프레임 지연이 지속되면 해상도 비율을 자동 낮추고 필요 시 그림자를 자동 비활성화
- 90Hz/120Hz/144Hz 화면에서도 남은 프레임 시간을 보존해 60fps 렌더링 간격 유지
- 건물 좌표를 Map 인덱스로 관리해 경로 탐색·컨베이어 인접 시설 검색을 상수 시간 조회로 처리
- 돌이 나무 재배기는 주변 반경 2타일의 13개 후보만 확인하며, 전역 자원 맵 스캔·정렬을 반복하지 않음
- 실제 쿨다운이 진행 중인 자원만 별도 목록으로 갱신해 매 시뮬레이션 틱의 전체 자원 순회를 제거
- 컨베이어 화물은 벨트당 최대 8개 시각 모델로 표시하되 실제 보유 수량·이동·생산 데이터는 그대로 보존
- GitHub Actions 정적 검사 및 Playwright WebGL/모바일 에뮬레이션 회귀 테스트 구성
- Engineer Skill Tree: 5개 분야, 20개 스킬 노드, 최대 15개의 중복 방지 마일스톤 포인트
- Save schema 검증, checksum, temp read-back, 3-slot backup rotation 및 유효 스냅샷 복구 테스트
- 현재 40개 챕터 BGM, 완전한 FluidNetwork/Shipping, 실기기 60분 soak, 전체 스킬 효과 연결은 구현 완료로 간주하지 않음
- 가상 1시간 테스트는 36,000회의 0.1초 고정 틱을 실행하며 실제 벽시계 60분 내구 테스트와 다릅니다.
- 모바일 에뮬레이션은 실제 Android/iPhone 기기 테스트가 아닙니다.
- 월드는 192×160 타일의 유한한 두 대륙 맵이며 무한 청크 스트리밍, 몬스터 전투, 멀티플레이는 포함하지 않습니다.
